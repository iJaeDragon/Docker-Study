# Docker 명령어 정리

## 명령어 구조
```
docker [리소스] [명령어] [옵션] [대상]
```
- 리소스: `container`, `image`, `network`, `volume` 등
- 특정 리소스에서만 유일하게 쓰이는 명령어는 **리소스명 생략 가능**
  - 예: `docker run` = `docker container run` (run은 container 전용이라 생략 가능)
  - 예: `docker rm` → 기본적으로 컨테이너 삭제 (컨테이너 쪽이 더 자주 쓰여서 생략 시 컨테이너로 인식)
  - 이미지를 삭제하려면 명확하게 `docker image rm`으로 명시해야 함

## 컨테이너 관련 명령어
| 명령어 | 설명 |
|---|---|
| `docker container ls` (`docker ps`) | 컨테이너 목록 확인 (기본은 실행 중인 것만) |
| `docker ps -a` | 생성/중지/실행 중인 **모든** 컨테이너 확인 |
| `docker stop` | 실행 중인 컨테이너 중지 |
| `docker rm` | 컨테이너 삭제 |
| `docker logs [id/name]` | 컨테이너 로그 확인 |
| `docker exec` | 실행 중인 컨테이너에 명령 전달 |
| `docker container inspect` | 컨테이너의 상세 설정/환경 조사 |

> 컨테이너 ID 대신 **컨테이너 이름**도 사용 가능

## 이미지 관련 명령어
| 명령어 | 설명 |
|---|---|
| `docker image ls` (`docker images`) | 이미지 목록 확인 |
| `docker image rm` | 이미지 삭제 (해당 이미지로 실행 중인 컨테이너가 있으면 **삭제 불가** → 컨테이너 종료 후 삭제해야 함) |
| `docker pull` | 이미지 다운로드 (이미지 전용 명령이라 `image` 생략 가능) |
| `docker push` | 이미지 업로드 |

## 기타
| 명령어 | 설명 |
|---|---|
| `docker network ls` / `inspect` | 네트워크 목록/상세 조사 |
| `docker system prune` | 중지된 컨테이너, 태그 없는(불명확한) 이미지, 미사용 네트워크를 한번에 정리 |

## 한 줄 정리
> `docker [리소스] [명령어]`가 기본 형태이며, 해당 명령이 특정 리소스에서만 쓰인다면 리소스명은 생략 가능하다. 삭제 시에는 어떤 리소스를 삭제하는지 명확히 하는 것이 안전하다.
