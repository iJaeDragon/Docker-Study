특정 컨테이너가 어떤 볼륨을 어느 경로에 마운트하고 있는지는 `docker inspect` 명령으로 확인할 수 있습니다.

가장 간단하게 필요한 정보만 뽑아서 보는 방법입니다.

```bash
docker inspect -f "{{json .Mounts}}" mssql2017
```

`mssql2017` 자리에 확인하고 싶은 컨테이너 이름을 넣으시면 됩니다. 결과가 JSON 한 줄로 나오는데, 보기 편하게 하려면 아래처럼 포맷을 지정할 수도 있습니다.

```bash
docker inspect -f "{{range .Mounts}}{{.Name}} -> {{.Destination}}{{println}}{{end}}" mssql2017
```

이렇게 하면 아래와 같이 "볼륨 이름 → 컨테이너 내부 경로" 형태로 깔끔하게 출력됩니다.

```
mssql2017-data -> /var/opt/mssql
```

왼쪽이 호스트 쪽 볼륨 이름, 오른쪽이 컨테이너 내부 마운트 경로입니다.

전체 정보를 다 보고 싶으시면 필터 없이 확인하셔도 됩니다.

```bash
docker inspect mssql2017
```

이 결과에서 `"Mounts"` 항목을 찾으면 `"Name"`(볼륨 이름), `"Source"`(호스트 실제 저장 경로), `"Destination"`(컨테이너 내부 경로) 정보를 모두 확인할 수 있습니다.

Windows cmd에서 `-f "{{...}}"` 형식이 따옴표 처리 때문에 에러가 난다면, 필터 없이 전체 출력을 보고 `Mounts` 부분만 눈으로 찾는 방법을 추천드립니다.

```cmd
docker inspect mssql2017
```
