# 로컬 레지스트리

## 로컬 레지스트리 실행
```
docker run -d -p 5000:5000 --name registry registry:2
```
- 공식 `registry` 이미지 사용 (태그 `2` 버전 사용)
- 기본적으로 **5000번 포트**로 서비스됨
- macOS에서 5000번 포트가 이미 사용 중이라고 뜨면, **시스템 설정 > AirPlay 수신 모드**가 원인인 경우가 많음 → 꺼주면 해결

## 레지스트리에 등록된 이미지(레파지토리) 확인
```
curl http://localhost:5000/v2/_catalog
```
- 브라우저에서 `localhost:5000/v2/_catalog`로 접속해도 동일하게 확인 가능
- 처음에는 등록된 이미지가 없어 빈 목록(`{"repositories":[]}`)이 표시됨

## 이미지를 로컬 레지스트리용으로 태그 변경
```
docker tag nodejs-demo:v2.0 localhost:5000/nodejs-demo1:v2
```
- `docker tag [기존이미지명:태그] [새이미지명:태그]`
- 새 이름 앞에 **로컬 레지스트리 주소(`localhost:5000`)**를 붙여야 함
- 태그 변경 후 `docker images`로 확인하면 **이미지 ID는 동일**, 이름만 달라진 것을 확인 가능
  - 원래 이미지: 아무 주소도 없으면 `docker.io`(Docker Hub)가 생략된 것
  - 태그명을 명시하지 않으면 자동으로 `latest`가 붙으므로, 원하는 태그가 있다면 반드시 명시할 것

## 로컬 레지스트리로 업로드(push)
```
docker push localhost:5000/nodejs-demo1:v2
```
- 이미지명 앞에 주소가 없으면 Docker Hub로 업로드됨 → 로컬 레지스트리로 보내려면 주소(`localhost:5000/...`)가 반드시 포함되어야 함
- push 후 `curl localhost:5000/v2/_catalog`로 다시 확인하면 등록된 레파지토리 목록에 표시됨

## 특정 이미지의 태그 목록 확인
```
curl http://localhost:5000/v2/nodejs-demo1/tags/list
```
- 해당 레파지토리에 등록된 태그들을 확인 가능 (예: `v2`)

## latest 태그도 함께 올리기
```
docker tag nodejs-demo:latest localhost:5000/nodejs-demo1:latest
docker push localhost:5000/nodejs-demo1:latest
```
- 로컬 PC에 있던 `latest` 이미지도 **로컬 레지스트리 주소로 다시 태그**한 후 push해야 함
- 완료 후 태그 목록을 확인하면 `v2`, `latest` 둘 다 표시됨

## 이미지 다운로드(pull)
```
docker pull localhost:5000/nodejs-demo1:v2
```
- 주소를 `localhost:5000`으로 지정하면 Docker Hub가 아닌 **로컬 레지스트리**에서 이미지를 받아옴

## 핵심 포인트
> 로컬 레지스트리를 쓰려면 이미지명 앞에 `localhost:5000/`처럼 **레지스트리 주소를 반드시 명시**해서 `tag`로 이름을 바꾼 뒤 `push`/`pull`해야 한다. 주소가 없으면 기본적으로 Docker Hub(`docker.io`)로 인식된다.
