# Node.js Dockerfile 단계별 빌드

## 목표
- `app.js`(Express 웹서버, 8000번 포트) + `package.json`(의존성 정의)로 구성된 Node 프로젝트를 Dockerfile로 이미지화

---

## 시도 1: 베이스 이미지를 `alpine`으로 시작 → 실패
```dockerfile
FROM alpine
RUN npm install
CMD ["node", "app.js"]
```
- `alpine`은 순수 리눅스 배포판(약 3MB)이라 **Node/npm이 설치되어 있지 않음**
- 오류: `npm: command not found`
- 원인: Node.js가 없는 상태에서 npm 명령을 실행하려 했기 때문

## 시도 2: 베이스 이미지를 `node:alpine`으로 변경 → 부분 성공, 새 오류
```dockerfile
FROM node:alpine
RUN npm install
CMD ["node", "app.js"]
```
- `node:alpine`: Node가 이미 설치된 경량 이미지 (약 48MB)
- npm 명령어는 실행되지만, **`package.json` 파일이 이미지 내부에 없어서** `npm install` 실패
- 원인: 소스 파일을 이미지 안으로 복사하는 과정이 빠짐

## 시도 3: `COPY`로 필요한 파일 복사 → 정상 빌드
```dockerfile
FROM node:alpine
COPY ./mynodejs/package.json ./package.json
COPY ./mynodejs/app.js ./app.js
RUN npm install
CMD ["node", "app.js"]
```
- `COPY [호스트경로] [이미지내경로]`: 호스트의 `package.json`, `app.js`를 이미지 루트로 복사
- `npm install`이 정상 실행되어 `node_modules` 설치됨
- 다만 파일들이 **이미지의 루트(`/`) 디렉토리**에 그대로 복사되는 건 보안/구조상 바람직하지 않음

## 시도 4 (최종): `WORKDIR`로 작업 디렉토리 지정
```dockerfile
FROM node:alpine
WORKDIR /home/node
COPY ./mynodejs/package.json ./package.json
COPY ./mynodejs/app.js ./app.js
RUN npm install
CMD ["node", "app.js"]
```
- `WORKDIR /home/node`: 이후의 `COPY`, `RUN` 등이 모두 이 디렉토리 기준으로 실행됨 (루트에 파일이 흩어지는 문제 해결)

---

## 빌드 & 실행 명령어

### 빌드 (버전마다 태그 구분)
```
docker build -t nodejs-demo:latest -f Dockerfile .      # 시도 1~3
docker build -t nodejs-demo:v2.0 -f Dockerfile .         # WORKDIR 적용 버전
```
- 태그명을 `latest`, `v2.0`처럼 구분해서 관리하면 **버전 관리처럼 활용** 가능

### 실행 (포트 매핑 + 이름 지정 + 백그라운드)
```
docker run -d -p 8000:8000 --name MyNode nodejs-demo:v2.0
```
- `-p 8000:8000`: 호스트 ↔ 컨테이너 포트 매핑
- `--name MyNode`: 컨테이너 이름 지정 (이미지명 앞이 아니라 옵션 자리에 위치)
- `-d`: 백그라운드 실행

### 접속 테스트
```
curl localhost:8000/
curl "localhost:8000/?name=철수"
```
- 브라우저 또는 `curl`로 확인 가능

### 컨테이너 내부 접속 시 주의
```
docker exec -it MyNode sh
```
- `node:alpine` 이미지에는 **`bash`가 없음** → `bash` 대신 `sh` 사용해야 함
- 마찬가지로 `curl` 명령어도 기본적으로 없을 수 있음 (경량 이미지의 특징)

---

## 핵심 포인트
> ① 실행 언어(Node 등)가 필요한 이미지는 **런타임이 이미 포함된 베이스 이미지**(`node:alpine`)를 쓰는 게 편하다.
> ② 소스 파일은 `COPY`로 반드시 이미지 내부에 넣어줘야 `RUN` 단계(`npm install` 등)가 정상 작동한다.
> ③ 파일이 루트에 흩어지지 않도록 `WORKDIR`로 작업 디렉토리를 지정하는 것이 좋다.
> ④ 경량 리눅스 베이스(alpine 계열)는 `bash`, `curl` 등 일부 명령어가 기본 포함되어 있지 않을 수 있다.
